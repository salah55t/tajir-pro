## TajirPro — repo notes (agent memory)

Arabic RTL offline SaaS for store management. Stack: Next.js 16 (App Router), Tailwind, shadcn/ui, Prisma + SQLite.

Commands:
- Dev: `npm run dev` (port 3000, logs to dev.log)
- Build: `npm run build` (standalone output) · Lint: `npx eslint src`
- DB: `npm run db:push` (needs `DATABASE_URL=file:<abs path>`)

Conventions:
- All UI copy is Arabic; layout is RTL. Use logical Tailwind utilities (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `rounded-ss-*`/`rounded-se-*`) — physical `left/right` and `rounded-ts/te` are wrong here.
- Server data flows through `useFetch` (`src/hooks/use-fetch.ts`); bump `version` via `onChanged()` to refetch all tabs.
- Shared types live in `src/lib/shared.ts`; API routes in `src/app/api/*/route.ts` return Arabic error messages.
- Each tab is a `src/components/<name>-tab.tsx` client component rendered from `src/app/page.tsx` with the `TABS` array.
- Dark mode uses `next-themes`; theme tokens are `oklch` in `src/app/globals.css`.
- `AGENTS.md` top block is auto-generated by `next dev`; keep it committed.
