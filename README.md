# تاجر برو — Tajir Pro 🛒

منصة SaaS مبسطة موجهة للتجار المحليين في الجزائر والسوق العربي، تجمع في مكان واحد:

1. **إدارة المخزون** — منتجات، كميات، أسعار، تنبيهات نفاد المخزون، وخصم/إعادة تلقائية عند الطلبات.
2. **ربط الطلبات بشركات التوصيل المحلية** — تعيين شركة توصيل لكل طلب، إرسال الطلب مع توليد رقم تتبع، وإشعار العميل تلقائياً.
3. **أتمتة الردود على العملاء** — مساعد ذكي يقرأ رسالة العميل ثم يفحص المخزون الحالي وسجل طلباته قبل الرد فوراً بالعربية.

## 📱 تطبيق الأندرويد (APK) — نسخة تعمل بدون إنترنت

يضم هذا المستودع أيضاً **تطبيق أندرويد أصلي** بنفس الوحدات الثلاث، بواجهة عربية RTL مصممة للهاتف، ويعمل **بدون إنترنت 100%** (البيانات محفوظة على الجهاز مع نسخ احتياطي JSON/CSV):

```
android/          ← مشروع Android كامل (Gradle 8.7 + AGP 8.5.2، بدون أي مكتبات خارجية)
.github/workflows/build-apk.yml   ← يبني APK تلقائياً على GitHub Actions
```

### تحميل APK جاهز
- **أسرع طريقة:** افتح [قسم Releases](../../releases) وحمّل `TajirPro-debug.apk` من Assets.
- أو من تبويب [Actions](../../actions) ← سير عمل **Build Android APK** ← حمّل الـ Artifact.

### البناء عبر GitHub (تلقائي)
أي `push` على `main` أو وسم `v*` — أو ضغطة يدوية من تبويب Actions — يُشغّل البناء وينتج APK خلال 3-5 دقائق.

### البناء محلياً
```bash
cd android
./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```
أو افتح مجلد `android/` مباشرة في Android Studio.

## الميزات بالتفصيل

### 📦 المخزون
- إدارة كاملة للمنتجات (إضافة/تعديل/حذف) مع رقم مرجع SKU وفئات وأسعار بيع وتكلفة.
- أزرار سريعة لزيادة/إنقاص الكمية مباشرة من الجدول.
- حد تنبيه لكل منتج مع تمييز بصري للمنتجات المنخفضة في لوحة التحكم.

### 🧾 الطلبات
- إنشاء طلب باختيار عميل (أو إضافة عميل جديد فوراً) وإضافة منتجات متعددة.
- التحقق التلقائي من كفاية المخزون قبل الحفظ، وخصم الكميات تلقائياً عند الإنشاء.
- إلغاء الطلب أو حذفه يعيد الكميات إلى المخزون تلقائياً.
- حالات الطلب: قيد الانتظار ← مؤكد ← قيد التجهيز ← قيد التوصيل ← تم التوصيل / ملغى.

### 🚚 التوصيل
- سجل شركات التوصيل المحلية (هاتف، نطاق التغطية، رسوم ثابتة، مفتاح API، Webhook).
- تفعيل/تعطيل الشركة دون حذفها.
- زر «إرسال للتوصيل» يحاكي تكامل API شركة التوصيل: يولّد رقم تتبع، يحدّث حالة الطلب، ويُبلغ العميل في محادثته تلقائياً.

### 🤖 الردود الآلية بالذكاء الاصطناعي
- مفتاح تفعيل/إيقاف عام في رأس الصفحة.
- عند وصول رسالة من عميل والخدمة مفعّلة، يولّد المساعد رداً بناءً على:
  - معلومات المتجر وساعات العمل وشخصية الرد المختارة (ودّي / رسمي / تسويقي / صبور).
  - قائمة المنتجات المتوفرة حالياً بأسعارها.
  - آخر 3 طلبات للعميل (حالتها، شركة التوصيل، رقم التتبع).
- زر «اقتراح رد» يدوي لمن يريد مراجعة الرد قبل الإرسال، مع إمكانية التعديل.
- زر «محاكاة رسالة واردة» لتجربة التدفق كاملاً مباشرة من الواجهة.

### 📊 لوحة التحكم
- إحصائيات: المنتجات، الطلبات النشطة، الإيرادات المحققة وقيد المعالجة، العملاء، الرسائل، عدد الردود الآلية.
- توزيع حالات الطلبات، تنبيهات المخزون المنخفض، أحدث الطلبات والرسائل.

## التقنيات المستخدمة

| الطبقة | التقنية |
|--------|---------|
| الواجهة | Next.js 16 (App Router) + React 19 + TypeScript 5 |
| التصميم | Tailwind CSS 4 + shadcn/ui + واجهة عربية RTL بخط Cairo |
| قاعدة البيانات | SQLite + Prisma ORM |
| الذكاء الاصطناعي | z-ai-web-dev-sdk (Chat Completions) — خادمي فقط |

## هيكل المشروع

```
src/
├── app/

│       ├── ai-reply/         # اقتراح رد ذكي يدوي
│       ├── settings/         # إعدادات المتجر والمساعد
│       ├── stats/            # إحصائيات لوحة التحكم
│       └── seed/             # بيانات تجريبية

├── hooks/use-fetch.ts        # خطاف جلب البيانات
└── lib/
    ├── db.ts                 # عميل Prisma
    ├── ai.ts                 # منطق المساعد الذكي
    └── shared.ts             # الأنواع والأدوات
```

## التشغيل محلياً

```bash
# 1) تثبيت الحزم
bun install   # أو npm install

# 2) ضبط متغير البيئة
echo 'DATABASE_URL=file:./db/custom.db' > .env

# 3) إنشاء قاعدة البيانات
bun run db:push

# 4) تشغيل خادم التطوير
bun run dev
```

ثم افتح `http://localhost:3000` واضغط زر **«بيانات تجريبية»** لتعبئة منتجات وعملاء وشركات توصيل جاهزة للتجربة.

## ملاحظات

- استدعاء الذكاء الاصطناعي يتم من الخادم فقط (`/api/messages`, `/api/ai-reply`) ولا تُكشف أي مفاتيح للعميل.
- تكامل شركات التوصيل حالياً بمحاكاة آمنة (توليد رقم تتبع محلي) — جاهز للربط مع API حقيقية عبر حقلي `apiKey` و`webhookUrl`.
- المشروع للعرض والتطوير؛ للإنتاج أضف مصادقة (NextAuth جاهز) وطبقة تعدد مستأجرين (multi-tenant).
