# تاجر برو — TajirPro 🛒

تطبيق أندرويد **لإدارة المتاجر وعملها بدون إنترنت**: نقطة بيع (POS) بقارئ باركود عبر كاميرا الهاتف، **طباعة الفواتير حرارياً عبر البلوتوث** مثل السوبر ماركت العالمية، **رمز تحقق فريد لكل فاتورة** لمنع الاحتيال، إدارة مخزون كاملة، **نظام اشتراك صالح لجهاز واحد مع التجديد**، **مركز تنبيهات للتحديثات وانتهاء الاشتراك**، **نظام قفل الميزات للنسخة المجانية (حد 3 منتجات)** — بواجهة عربية RTL بتصميم عصري أنيق.

> 💡 البيانات محفوظة على الجهاز بالكامل (localStorage) — لا يحتاج إنترنت ولا حساب ولا خادم.

## ✨ الميزات

### 🔒 نظام القفل (Trial Mode) — جديد v1.8.0
- **النسخة المجانية (غير المفعّلة):**
  - حد أقصى **3 منتجات** في المخزون
  - **بدون طباعة** الفواتير الحرارية
  - **بدون نسخ احتياطي** (تصدير/استيراد JSON)
  - **بدون تصدير CSV**
  - **بدون مسح شامل** للبيانات
  - لافتات تنبيه مرئية في لوحة التحكم والمخزون والإعدادات
  - شاشة قفل جذابة تطلب التفعيل عند الوصول لميزة مقفلة
- **النسخة المفعّلة (اشتراك ساري):**
  - **منتجات غير محدودة**
  - جميع الميزات مفتوحة بلا قيود
  - لا لافتات قفل — تجربة استخدام كاملة

### 🔑 مولّد المفاتيح (برنامج المسؤول) — جديد v1.8.0
ثلاث طرق لتوليد أكواد الاشتراك:
1. **برنامج سطح المكتب (Python tkinter GUI):** `scripts/keygen_app.py`
   - واجهة عربية كاملة مع سجل الأكواد المُولّدة
   - تصدير CSV/JSON للسجل
   - تجميع كملف تنفيذي عبر PyInstaller: `pyinstaller --onefile --windowed scripts/keygen_app.py`
2. **صفحة HTML مستقلة:** `scripts/keygen.html`
   - تعمل في أي متصفح بدون تثبيت
   - سجل محلي في localStorage + تصدير CSV/JSON
3. **سكربت سطر الأوامر:** `scripts/generate_code.py`
   - للأتمتة والاستخدام البرمجي

### 🔔 مركز التنبيهات والاشتراك (v1.7.0)
- **زر جرس التنبيهات** أعلى الشاشة مع شارة عدّ رقمية تتحدث تلقائياً.
- **مركز تنبيهات موحّد** يجمع: حالة الاشتراك، نفاد المخزون، انتهاء الصلاحية، وفحص التحديثات.
- **إشعارات نظام محلية** (Android Notifications) عند اقتراب انتهاء الاشتراك أو انتهائه.
- **نظام اشتراك صالح لجهاز واحد فقط**: كل كود مرتبط ببصمة الجهاز (SHA-256) ولا يعمل على جهاز آخر.
- **التجديد بنفس الكود أو كود جديد**: أدخل كود التجديد في أي وقت لتمديد فترة الاشتراك.
- **أداة توليد أكواد للمسؤول** (Python): `scripts/generate_code.py` لتوليد أكواد صالحة لكل جهاز.

#### صيغة كود الاشتراك
```
TJP-{مدة_بالأيام}-{بصمة_الجهاز_8حروف}-{تاريخ_الانتهاء_base36}-{تحقق_2حروف}
مثال: TJP-365-A1B2C3D4-G2B-B4
```
- **مدة**: عدد أيام الاشتراك (30، 90، 180، 365…).
- **بصمة الجهاز**: 8 محارف سداسية عشر تُعرض داخل التطبيق (الإعدادات ← الاشتراك).
- **تاريخ الانتهاء**: عدد الأيام منذ 1970-01-01 بترميز base36.
- **تحقق**: حرفان من مجموع تحقق متعدد الحدود لضمان سلامة الكود.

#### توليد كود للمسؤول
```bash
python scripts/generate_code.py A1B2C3D4 30          # 30 يوماً من اليوم
python scripts/generate_code.py A1B2C3D4 365 2026-01-01  # سنة من تاريخ محدد
```
أو من داخل التطبيق: الإعدادات ← الاشتراك ← مولّد الأكواد (مسؤول).

### 🖨️ طباعة الفواتير حرارياً عبر البلوتوث
- طباعة الفاتورة على أي **طابعة حرارية بلوتوث (ESC/POS)** بمقاس 58mm أو 80mm — مثل السوبر ماركت العالمية.
- الفاتورة تحمل **اسم المتجر وهاتفها**، الأصناف والكميات، الخصم والإجمالي والمدفوع والباقي.
- **رمز QR وكود تحقق فريد لكل فاتورة** (`TJ-XXXX-XX`) مطبوع أسفلها.
- العربية تُرسم داخل التطبيق ثم تُرسل للطابعة كصورة نقطية دقيقة — تشكيل عربي صحيح على أي طابعة مهما كانت دعمها للغات.
- زر طباعة يظهر مباشرة بعد كل بيع، وأيضاً في سجل المبيعات، مع طباعة تجريبية من الإعدادات.

### 🛡️ التحقق من الفواتير ومكافحة الاحتيال
- تبويب «تحقق من فاتورة» في نقطة البيع: امسح رمز QR أو الكود المطبوع على الفاتورة.
- يعرض التطبيق **الفاتورة المخزنة فعلياً**: الأصناف، الإجمالي، التاريخ، وحالة «فاتورة أصلية ✓».
- الفاتورة المُرجَعة تظهر عليها **تحذير أحمر** فوراً، وأي كود غير معروف يعطي رسالة «رمز غير معروف» — لا يمكن تمرير فاتورة مزيفة أو معدّلة.

### 🛒 بيع منتجات بدون باركود + سعر مباشر
- زر **«سعر مباشر»** في نقطة البيع: أدخل السعر والكمية (والاسم اختيارياً) — يُضاف للسلة **فوراً** بدون أي منتج مسجل، مثالي للسلع السائبة (خضار، فواكه، أوزان مفتوحة). لا يخصم من المخزون ولا يتطلب تسجيلاً مسبقاً.
- زر «بدون باركود» الثاني يفتح **قائمة المخزون** مع بحث فوري — اضغط على منتج مسجل (حتى بدون باركود) ليُضاف بسعره ويُخصم من مخزونه.
- شارة «متوفر» لكل منتج، ووسم «نفدت» للمنتجات غير المتاحة، وشارة «بدون باركود» في بطاقات المخزون.
- إدخال متسلسل سريع: بعد كل إضافة تُفرغ الحقول ويبقى المؤشر على حقل السعر.

### 📷 نقطة البيع السريعة (POS)
- مسح باركود المنتجات بكاميرا الهاتف (EAN / UPC / QR...) — يُضاف المنتج للسلة ويُحسب المجموع تلقائياً.
- إدخال رقم الباركود يدوياً كبديل، مع مصباح (فلاش) للإضاءة الضعيفة.
- صوت تنبيه + اهتزاز عند كل مسح ناجح (قابل للتعطيل من الإعدادات).
- خصم مباشر، حساب الباقي للعميل، وأزرار دفع سريعة (+100 / +500 / +1000).
- إيصال بيع فوري قابل للمشاركة عبر واتساب، مع إمكانية إرجاع البيع وإعادة الكميات للمخزون.
- سجل مبيعات مجمّع حسب اليوم مع إحصائيات (اليوم / آخر 7 أيام / الإجمالي).

### 📦 إدارة المخزون
- إضافة منتج بـ: الاسم، الباركود (مسح بالكاميرا أو إدخال)، التصنيف، سعر البيع والتكلفة، الكمية، حد التنبيه، وتاريخ انتهاء الصلاحية.
- إدخال / إخراج مخزون مع سجل حركات كامل (شراء، بيع، تعديل، إرجاع).
- بحث فوري بالاسم أو التصنيف أو الباركود، وفلترة بالتصنيفات.
- منع البيع بكمية أكبر من المتوفر، ومنع تكرار نفس الباركود لمنتجين.

### 🔔 مركز التنبيهات
- تنبيهات نفاد المخزون (منتجات نفدت + منتجات منخفضة) مع إدخال سريع للكميات.
- تنبيهات الصلاحية (منتهية + تنتهي قريباً حسب حد التحذير القابل للتعديل).
- تنبيهات الاشتراك (ينتهي قريباً / منتهي) مع إمكانية التجديد المباشر.

### 🗄️ النسخ الاحتياطي
- تصدير/استيراد نسخة كاملة (JSON)، وتصدير المخزون CSV يدعم العربية.
- مسح شامل للبيانات عند الحاجة.

## 📱 تحميل التطبيق (APK)

- **أسرع طريقة:** افتح [قسم Releases](../../releases) وحمّل أحدث APK من Assets.
- أو من تبويب [Actions](../../actions) ← سير عمل **Build Android APK** ← حمّل الـ Artifact.

## 🔨 البناء

### عبر GitHub (تلقائي)
أي `push` على `main` أو وسم `v*` — أو ضغطة يدوية من تبويب Actions — يُشغّل البناء وينتج APK خلال 3-5 دقائق.

### محلياً
```bash
cd android
./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```
أو افتح مجلد `android/` مباشرة في Android Studio.

## 🧰 التقنيات

| المكوّن | التقنية |
|---------|---------|
| التطبيق | Android (WebView أصلي، minSdk 21 → targetSdk 34) |
| الواجهة | HTML/CSS/JS عربي RTL داخل أصول التطبيق (offline-first) |
| القارئ | html5-qrcode عبر getUserMedia داخل WebView آمن (WebViewAssetLoader) |
| الطباعة | بلوتوث SPP + أوامر ESC/POS (GS v 0) + رسم Canvas عربي + QR عبر zxing |
| البناء | Gradle 8.7 + AGP 8.5.2 + GitHub Actions CI |
